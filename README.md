# Pratima Awa — Portfolio

Personal portfolio built with Next.js (App Router), TypeScript and Tailwind CSS v4. All pages are static Server Components.

Content lives in `src/content/site.ts`; the Onta Trips case study is `src/app/work/onta-trips/page.tsx`.

```bash
yarn dev           # http://localhost:3000
yarn type-check
yarn lint
yarn format:check
yarn build
```
